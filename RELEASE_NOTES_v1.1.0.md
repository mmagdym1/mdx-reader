# MDX Reader v1.1.0

## English

MDX Reader is a Windows and browser Markdown viewer/editor built specifically for mixed Arabic-English documents.

### Highlights

- Smart direction detection counts Arabic and Latin letters per block instead of trusting the first character.
- Inline code, links, and numbers use bidi isolation; fenced code stays LTR.
- GFM tables, task lists, GitHub callouts, footnotes, reference links, front matter, and syntax highlighting.
- Preview, synchronized split, and editor modes with four themes and typography controls.
- Diacritic- and hamza-insensitive Arabic search, generated outline, autosave, HTML export, and print/PDF.
- Installer with Markdown file associations, portable Windows executable, and offline single-file web app.

Use **Setup** for installation and `.md` file association, or **Portable** to run without installing.

## العربية

MDX Reader عارض ومحرر Markdown لويندوز والمتصفح، مخصص للمستندات المختلطة بالعربية والإنجليزية.

### أبرز ما في الإصدار

- اكتشاف ذكي للاتجاه يحسب الحروف العربية واللاتينية داخل كل عنصر بدل الاعتماد على أول حرف.
- عزل اتجاهي للكود السطري والروابط والأرقام، مع تثبيت كتل الكود على LTR.
- دعم الجداول وقوائم المهام واقتباسات GitHub والحواشي والروابط المرجعية وبيانات front matter وتلوين الكود.
- أوضاع المعاينة والمقسوم والتحرير، وأربعة ثيمات وتحكم بالخط.
- بحث عربي يتجاهل التشكيل والهمزات، وفهرس تلقائي، وحفظ تلقائي، وتصدير HTML، وطباعة/PDF.
- مُثبت يربط ملفات Markdown بالنظام، ونسخة ويندوز محمولة، ونسخة ويب مستقلة تعمل دون إنترنت.

استخدم ملف **Setup** للتثبيت وربط امتدادات Markdown، أو **Portable** للتشغيل دون تثبيت.
